Kinopub для Movian — установка
==============================

В этом архиве:
  kinopub.zip   — плагин. Не переименовывайте и не распаковывайте его.
  Инструкция по установке.txt — эта инструкция.

Требования
----------
Movian версии 5.0 или новее (нужна поддержка TLS 1.2). На PlayStation 3 —
актуальная сборка Movian M7 7.x. Нужна подписка kino.pub.

Способ 0. Из списка плагинов Movian (самый простой)
-----------------------------------------------------
1. В Movian: Settings -> General -> «Alternate plugin Repository URL», впишите адрес
     http://tinyurl.com/m7kinopub
   Если он не открывается, впишите полный:
     https://raw.githubusercontent.com/mranalogman/movian-kinopub/main/plugins-v1.json
2. Settings -> Plugins -> «Browse available plugins», найдите Kinopub и нажмите «Install».
   Обновления дальше будут приходить прямо в Movian.

Способ 1. Через файловый менеджер Movian
--------------------------------------------------------
1. Скопируйте kinopub.zip на флешку.
2. Вставьте флешку в приставку, в Movian откройте раздел файлов и найдите kinopub.zip.
3. Нажмите на файл — Movian распознает его как плагин и установит.
   Если плагин уже был установлен, он обновится, настройки и вход сохранятся.

Способ 2. По FTP (на PS3 — через webMAN MOD)
--------------------------------------------
1. Подключитесь к приставке FTP-клиентом.
2. Положите kinopub.zip в папку
     /dev_hdd0/game/HTSS00003/USRDIR/settings/installedplugins/
   именно под именем kinopub.zip. Если там лежат старые архивы этого плагина
   с другими именами, удалите их, иначе Movian может загрузить старую версию.
3. Перезапустите Movian.

Первый запуск
-------------
На главном экране Movian появится иконка Kinopub. При первом открытии плагин
покажет код активации. Введите его на сайте kino.pub в разделе «Мои устройства».
Дальше плагин работает сам, повторная активация не нужна.

Настройки
---------
Settings -> «Applications and installed plugins» -> Kinopub: протокол видео,
качество, предпочитаемая озвучка, субтитры, синхронизация просмотра с kino.pub.
Адрес API определяется автоматически, вводить ничего не нужно.

Если каталог перестал открываться
---------------------------------
Settings -> «Applications and installed plugins» -> Kinopub -> «Обновить адрес API
сейчас». Если не помогло, проверьте «Адрес конфигурации» (тот же адрес, что
вводится в MicroIPTV на Apple TV) и повторите. В крайнем случае впишите рабочий
адрес API в «Адрес API вручную», а после починки очистите это поле.

Если что-то не работает
-----------------------
Лог Movian доступен в браузере по адресу http://<IP приставки>:42000/ ,
строки плагина помечены [kinopub]. Приложите их к сообщению об ошибке.
