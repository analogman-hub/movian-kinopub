# Kinopub для Movian

Плагин [Movian](https://movian.tv) (проверен на Movian M7 7.0.273 для PlayStation 3) для просмотра
[kino.pub](https://kino.pub) по официальному API. Нужна подписка Kinopub.

## Возможности

- Активация устройства кодом, как в других клиентах Kinopub; токены хранятся в Movian и обновляются сами.
- Каталог по типам, «Свежее», «Горячее», «Популярное», закладки, «Я смотрю» с пометкой новых серий.
- Поиск по Kinopub с экранной клавиатуры.
- Карточки с постером, годом, жанрами и рейтингами; описание и список актёров открываются отдельными страницами,
  трейлер воспроизводится прямо из карточки. У серий значок статуса: `✓` просмотрено, `▶` начато, `•` не смотрели.
- Воспроизведение через HLS: качество подбирает Movian, все озвучки переключаются в плеере.
- Внешние субтитры доступны в плеере, но по умолчанию выключены.
- Синхронизация с kino.pub: позиция просмотра, автоматическая отметка досмотренных серий,
  ручные отметки «просмотрено» и «Буду смотреть» в контекстном меню.
- Адрес API определяется автоматически так же, как это делает приложение Kinopub для Apple TV,
  и обновляется при смене адресов у сервиса. Ничего вводить не нужно.

## Требования

- Movian с поддержкой TLS 1.2: версия 5.0 и новее. На PS3 рекомендуется актуальная сборка M7 7.x.
- PS3 декодирует только H.264, поэтому плагин выбирает h264-файлы; HEVC и 4K на приставке не воспроизводятся.

## Установка

### Из списка плагинов Movian (рекомендуется)

1. Settings → General → «Alternate plugin Repository URL», впишите короткий адрес:

   ```
   http://tinyurl.com/m7kinopub
   ```

   Если короткий адрес перестанет открываться, впишите полный:

   ```
   https://raw.githubusercontent.com/analogman-hub/movian-kinopub/main/plugins-v1.json
   ```

2. Settings → Plugins → «Browse available plugins», найдите Kinopub и нажмите Install.

Обновления после этого приходят прямо в Movian.

### Вручную

Скачайте `movian-kinopub-<версия>.zip` со страницы
[последнего релиза](https://github.com/analogman-hub/movian-kinopub/releases/latest). Внутри сам плагин
`kinopub.zip` и инструкция по установке. Имя `kinopub.zip` менять нельзя: Movian хранит установленные плагины
по имени файла, и архив с другим именем встанет рядом со старым, а не заменит его.

Способ 1, через файловый менеджер Movian: скопируйте `kinopub.zip` на флешку, откройте его в Movian в разделе
файлов, плагин установится сам.

Способ 2, по FTP (на PS3 через webMAN MOD): положите `kinopub.zip` в
`/dev_hdd0/game/HTSS00003/USRDIR/settings/installedplugins/`, удалите оттуда старые архивы плагина
и перезапустите Movian.

### Первый запуск

На главном экране Movian появится Kinopub. При первом открытии плагин покажет код, введите его на kino.pub
в разделе «Мои устройства».

## Использование

- Главная страница плагина: поиск, «Я смотрю», закладки, подборки и типы контента.
- Контекстное меню серии (на PS3 кнопка «квадрат»): «Отметить просмотр на Kinopub» и выбор озвучки.
  Выбранная озвучка становится дорожкой по умолчанию, остальные остаются доступны в плеере.
- У сериалов в списках и в карточке: «Kinopub: добавить в „Буду смотреть“».
- Субтитры: в плеере первой стоит дорожка «Без субтитров», настоящие включаются в меню субтитров плеера.
- Позиция просмотра отправляется на kino.pub при паузе, выходе из серии и раз в минуту.
- Автоотметка: когда до конца серии остаётся не больше 5% или двух минут и до этой точки дошли просмотром,
  а не перемоткой (или серию закрыли в этой зоне), плагин ставит отметку на kino.pub, если её ещё нет.

## Настройки

Settings → «Applications and installed plugins» → Kinopub.

| Настройка | Что делает |
|---|---|
| Адрес конфигурации | Откуда берётся актуальный адрес API. По умолчанию подходит, менять только если Kinopub сменит адрес. |
| Адрес API вручную | Переопределяет автоматическое определение. Пусто = автоматически. |
| Обновить адрес API сейчас | Принудительная проверка, результат всплывает на экране. |
| Протокол видео | HLS4 (все озвучки, качество автоматически), HLS (одна озвучка), MP4 по HTTP. |
| Максимальное качество | Действует для HLS и MP4. |
| Предпочитаемая озвучка | Часть названия, например `LostFilm`. Серии стартуют с этой дорожкой. |
| Включать субтитры автоматически | Убирает заглушку «Без субтитров». |
| Отправлять позицию просмотра | Синхронизация с kino.pub и автоотметка. |
| Выйти из аккаунта | Удаляет токены, при следующем запуске нужна активация. |

## Если каталог перестал открываться

Kinopub время от времени меняет адреса серверов. Плагин отслеживает это сам, но если каталог не грузится:

1. Откройте Settings → «Applications and installed plugins» → Kinopub и нажмите «Обновить адрес API сейчас».
   На экране всплывёт найденный адрес или текст ошибки.
2. Если ошибка повторяется, проверьте «Адрес конфигурации»: это тот же адрес, что вводится в MicroIPTV
   на Apple TV. Впишите актуальный, если Kinopub его сменил, и снова нажмите «Обновить адрес API сейчас».
3. Крайний случай: впишите известный рабочий адрес API в «Адрес API вручную». Пока поле заполнено,
   автоматическое определение выключено, поэтому после починки очистите его.

Проверить сеть и TLS с приставки можно плагином из `tools/tlscheck` (см. «Диагностика»).

## Известные ограничения

- В списке аудиодорожек плеера Movian показывает только язык, а не название озвучки: при разборе HLS
  он не заполняет заголовок дорожки. Название показывается всплывающим уведомлением при старте и при
  каждом переключении, а полный список с названиями есть в контекстном меню серии.
- Начать серию с позиции, сохранённой на другом устройстве, нельзя: Movian берёт позицию из своей памяти.

## Диагностика

Лог Movian доступен по адресу `http://<IP приставки>:42000/`, строки плагина помечены `[kinopub]`.
В `tools/tlscheck` лежит отдельный плагин, который проверяет TLS-соединения Movian с хостами Kinopub;
собирается командой `make tlscheck.zip`.

## Сборка

```
make              # movian-kinopub-<версия>.zip: kinopub.zip + инструкция по установке
make kinopub.zip  # только плагин
make repo         # plugins-v1.json для репозитория плагинов Movian
make check        # проверка синтаксиса (нужен node)
```

Релиз: поднять версию в `plugin.json`, закоммитить, поставить тег `v<версия>` и запушить его. GitHub Actions
соберёт архивы, опубликует релиз и обновит `plugins-v1.json` в ветке `main`.
